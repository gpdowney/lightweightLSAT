# lightweight-lsat v0.8

[*The lightweight LSAT*](https://lightweightlsat.com) is a simple, proven, and completely free guide to the LSAT.

## About the website

The site is built with ProperDocs (a fork of MkDocs) using the Material theme to take advantage of built-in features like search and navigation. It is hosted on Cloudflare Pages.

Here on GitHub you'll find the actual content of the site in the markdown files in the "docs" folder.
